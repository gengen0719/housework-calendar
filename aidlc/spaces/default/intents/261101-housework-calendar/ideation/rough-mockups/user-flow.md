# 操作の流れ（User Flow）

最初の版の主な操作の流れです。画面の番号（S1〜S6、T1・T2）は `wireframes.md` と同じです。もとにしたのは次の 4 つです。

- 「意図の整理」（`ideation/intent-capture/intent-statement.md`）
- 「範囲の定義」（`ideation/scope-definition/scope-document.md`）
- 「作業一覧」（`ideation/scope-definition/intent-backlog.md`）
- `rough-mockups-questions.md` の回答

## F1. 月初の準備（母親）

- **きっかけ:** 月の初めに、家族で割り当てを話し合って決めたあと（`scope-document.md`）
- **手順:**
  1. S3 でお手伝いの種類を確認する。必要なら追加や変更をする → 保存される
  2. S4 を開き、お手伝いの種類ごとに担当の子供と曜日を選ぶ → 担当の重なりがあれば知らせる
  3. 「保存」を押す → その月の日ごとの割り当てができ、S1 に表示される
  4. 例外の日は、S1 から日付を選んで S2 の「担当を変える」で直す → その日の担当が変わる
- **終わったときの状態:** S1 で、その月の全員の担当が見える
- **うまくいかなかったとき:**
  - お手伝いの種類が 1 つもない → S4 に「先にお手伝いの種類を追加してください」と S3 へのボタンを出す
  - 保存に失敗した → 「保存できませんでした」と出し、入力した内容は残す。もう一度保存できる

## F2. 毎日の記録（子供）

- **きっかけ:** 16 時のリマインドを見る。または、お手伝いが終わったとき（`scope-document.md`）
- **手順:**
  1. 公式アカウントとの 1 対 1 のトークで、リッチメニューの「やった」をタップする → 自分の今日の担当がボタンで出る
  2. やったお手伝いを選ぶ → 記録され、記録した時刻が残る。「皿洗いを記録しました（16:42）」と本人に返事が届く
- **終わったときの状態:** S1・S2 で、そのお手伝いが「済」になり、記録した時刻も見える。お小遣いの回数に数えられる
- **うまくいかなかったとき:**
  - 今日の担当がない → 「今日の担当はありません」と返事する
  - すでに記録した → そのお手伝いは「済」と表示し、選べないようにする
  - 記録に失敗した → 「記録できませんでした。もう一度お試しください」と返事する
- **グループへのお知らせ:** 記録したことはグループには知らせない。母親はアプリで確認する（Q8）

## F3. 記録の確認と修正（母親）

- **きっかけ:** 母親がアプリを開いたとき（`scope-document.md`）
- **手順:**
  1. S1 で、「済」「未」「×」を見る
  2. 気になる日を選んで S2 を開く
  3. 実際にはやっていない記録は、「記録を取り消す」を押す → 確認が出て、OK で取り消される。回数から外れる
  4. やらなかった担当は、「やらなかったにする」を押す → 確認が出て、OK で「×」になる
  5. 必要なら、S6 で理由を書いて加算・減額を入力する（IB-9）
- **終わったときの状態:** S5 のお小遣い額に、取り消しと加算・減額が反映されている

## F4. 枠の交換（子供同士）

- **きっかけ:** 子供が、自分の担当の日を誰かと交換したいとき（`scope-document.md`）
- **手順:**
  1. 子供 A がグループのトークで「交換」と送る → 公式アカウントが、A のこれからの担当をボタンで返事する
  2. A が交換したい担当を選ぶ → 公式アカウントが、ほかの子供の担当をボタンで並べて、申し出をグループに返事する
  3. 子供 B が、自分の担当のボタンを押して承諾する → 2 つの担当が入れ替わる。「交換しました」と返事が届く
- **終わったときの状態:** S1 で、2 つの担当が入れ替わっている
- **うまくいかなかったとき:**
  - 申し出た子供本人や母親が承諾ボタンを押した → 「この申し出には応えられません」と返事する
  - 承諾の前に、その日がすでに過ぎていた → 「この担当はもう交換できません」と返事する

## F5. 月末のまとめ（全員）

- **きっかけ:** 月の最後の日（`scope-document.md`）
- **手順:**
  1. 公式アカウントが、各子供のお小遣い額をグループに送る
  2. 誰でも S5 を開いて、内訳（単価 × 回数、加算・減額）を見られる
- **終わったときの状態:** 家族全員が、その月のお小遣い額を知っている。実際の支払いは、アプリの外で行う（`scope-document.md`）

## Assumptions & Open Questions

- [assumption] F4 は、グループのトークで「交換」と送って始める形にした（`wireframes.md` と同じ前提）
- [assumption] 交換できるのは、まだ過ぎていない日の担当どうしとした
- [assumption] 月末のまとめは、月の最後の日に送る。何時に送るかは、要件の段階で決める
