# 範囲の定義（Scope Document）

この書類は、最初の版でやることとやらないことの境界を決めたものです。もとにしたのは次の 4 つです。

- 「意図の整理」（`ideation/intent-capture/intent-statement.md`）
- 「実現可能性の評価」（`ideation/feasibility/feasibility-assessment.md`）
- 「制約の一覧」（`ideation/feasibility/constraint-register.md`）
- 「範囲の定義」の質問への回答（`scope-definition-questions.md` の Q1〜Q8）

## 最初の版の目的

月の初めに家族で決めた割り当てを母親が入力すると、子供がそれを見ながら実施結果を記録し、月末にお小遣い額が自動で計算される状態を目指します。母親は記録を確認するだけで済むようにします（intent-statement の成功の目安）。

## 最初の版に入れるもの（In Scope）

| 機能 | 内容 | 出典 |
|------|------|------|
| 家族だけが使える LINE アプリ | LINE の認証で家族のメンバーを見分ける。家族以外は使えない | intent-statement、constraint-register の C-T1・C-R1 |
| お手伝いの種類の管理 | 母親が種類ごとに名前・単価・説明（やり方や、できたと言える基準）を設定する | intent-statement、Q6 |
| 月初の割り当ての入力 | 家族で話し合って決めた「どの日のどのお手伝いを誰がやるか」を、母親だけが入力する | intent-statement |
| カレンダーの表示 | 子供も含めて全員が、家族全員の担当とお小遣い額を見られる | Q5 |
| 実施結果の記録 | 子供がグループのトークで公式アカウントに話しかけて記録する。公式アカウントは返事で「記録しました」を知らせる。記録した時刻も残す | intent-statement、feasibility-assessment、constraint-register の C-T3 |
| 記録の確認と修正 | 子供が記録した時点で回数に数える。母親はあとから記録を取り消せる。「やらなかった」は母親が記録する（自動では判定しない） | Q1・Q2 |
| 子供同士の枠の交換 | 子供がアプリで交換を申し出て、相手の子供が承諾すれば交換される | intent-statement |
| お小遣いの計算 | 「お手伝いの種類ごとの単価（全員共通）× 実施回数」を合計する | intent-statement |
| 任意の加算・減額 | 母親が理由を書いて、任意の額を加算・減額する。ボーナス・ペナルティはこの方式だけにする | Q3 |
| 毎日のリマインド | 毎日夕方の決まった時刻（例: 16 時）に 1 回、その日の担当を家族のグループ LINE に送る | Q4、constraint-register の C-T4 |
| 月末のまとめ | 月末に、各子供のお小遣い額をまとめて家族のグループ LINE に送る | intent-statement |

## 最初の版でやらないもの（Out of Scope）

| やらないもの | 出典 |
|--------------|------|
| お小遣いの実際の支払い（送金や決済）。アプリでは金額の計算と記録だけを行う | intent-statement |
| 割り当て作業の自動化（前月の割り当てのコピー、自動割り当て） | intent-statement |
| 過去の月の履歴をグラフなどで振り返る機能 | intent-statement |
| アプリの中で家族が話し合って、割り当てやルールを決める機能 | intent-statement |
| 「やらなかった」の自動判定 | Q2 |
| 決まった条件で自動的に付くボーナス・ペナルティ（全部できたら加算、やらなかったら 1 回ごとに減額など） | Q3 |
| 1 日 2 回以上のリマインド | constraint-register の C-T4 |

## 遅れた場合の扱い

| 状況 | 対応 | 出典 |
|------|------|------|
| 2026 年 12 月の月初に間に合わない | 12 月までは紙やホワイトボードで管理する。全部そろえてから、2027 年 1 月の月初に使い始める | feasibility-assessment |
| 2027 年 1 月の月初にも間に合いそうにない | 任意の加算・減額だけを最初の版から外し、あとで追加する。ほかの機能は外さない | Q7 |

## 作る順番

使う流れの順に作ります（Q8）。

1. お手伝いの種類
2. 割り当て
3. 記録
4. お小遣いの計算
5. お知らせ

## 価値の流れ（Value Stream）

家族が月初に話し合ってから、月末にお小遣い額を受け取るまでの流れです。

```
[家族で話し合い] --> [母親が割り当てを入力] --> [毎日 16 時にリマインド]
      --> [子供がトークで記録 / 返事で「記録しました」] --> [母親が確認・取り消し・「やらなかった」の記録]
      --> [月末にお小遣い額を計算] --> [グループ LINE にまとめを送る]
```

## Assumptions & Open Questions

- [assumption] グループのトークで話しかけた子供を、アプリが見分けられる（raid-log の R-3）。見分けられなければ、記録の方法を見直す必要がある。作る順番は使う流れのとおりとしたため、この確認は「記録」を作る段階で行うことになる
- [assumption] LINE 公式アカウントの無料枠は、月 200 通まで（feasibility-assessment）
