# 機能設計 — U2 招待 — 質問

U2（`u2-invitation`）では、管理者（お母さん）が招待用のリンクを作り、子供がそのリンクで家族に入る流れを作ります。受け持つ受け入れ条件は AC1.1.6〜AC1.1.9 と AC1.1.13 です（`inception/units-generation/unit-of-work-story-map.md`）。家族のメンバーの一覧（`GET /v1/family/members`）も、U2 で画面に出します（U1 の機能設計で U2 に回したもの）。

すでに決まっていること（もう一度は聞きません）:

- 招待用のリンクを作れるのは管理者だけで、子供が作ろうとすると断る（AC1.1.13、BR2.4 の仕組みを使う）
- 招待で参加した人は、その家族の子供になる（FR1.4）
- すでに別の家族に入っている人は参加できず、「すでに別の家族に入っています」と出す（AC1.1.8）
- 無効なリンクでは参加できず、「この招待は使えません。管理者に新しい招待を頼んでください」と出す（AC1.1.9）
- 友だち登録していない人・ブロック中の人は、U1 のとおり友だち登録の案内だけを出す（招待のリンクを開いても同じ）
- 新しく作る操作は、送り直しを 1 回として扱う（`Idempotency-Key`。U1 の BR2.8）

要件の Open Questions に残っていた「招待用のリンクに有効期限を付けるか、何回使えるか」と、ここで決める細かい扱いを聞きます。
