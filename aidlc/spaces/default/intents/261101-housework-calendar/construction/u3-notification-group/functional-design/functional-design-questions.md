# 機能設計 — U3 お知らせ先 — 質問

U3（`u3-notification-group`）では、管理者（お母さん）が公式アカウントを家族のグループ LINE に招待し、そのグループをお知らせ先として登録する流れを作ります。受け持つ受け入れ条件は AC1.2.1〜AC1.2.5 です（AC1.2.4 は画面の表示まで。「16 時と月末 21 時に何も送らない」は U10、AC1.2.5 は断る決まりまで。申し出そのものは U8）。

すでに決まっていること（もう一度は聞きません）:

- お知らせ先は 1 家族に 1 つで、登録し直すと新しいグループに置き換わる（FR1.5、AC1.2.2）
- 子供は登録できず、「お知らせ先を登録できるのは管理者だけです」と返事する（AC1.2.3）
- お知らせ先がないとき、管理者が画面を開くと「お知らせ先のグループが登録されていません」と出す（AC1.2.4）
- 登録されていないグループでの申し出には、「このグループは家族のお知らせ先として登録されていません」と返事する（AC1.2.5）
- LINE から届いたイベントは署名を確かめ、同じイベントは二度処理しない（U1 の BR2.6、BR2.7）
- 返事は reply（無料）で送り、push は使わない（費用 0 円。U1 と同じ）

契約の Open Questions に残っていた「グループでお知らせ先を登録する操作の言葉と、ボタンの形」と、ここで決める細かい扱いを聞きます。

## Q1. [プロダクト] お知らせ先を登録する操作

管理者がグループの中で、そのグループをお知らせ先にする操作です。

A. 公式アカウントがグループに参加したときに、「このグループをお知らせ先にする」ボタンつきのあいさつを送る。管理者がボタンを押すと登録する。あわせて、グループで「登録」と送っても登録できる（ボタンが流れて見えなくなったとき用）
B. 管理者がグループで「登録」と送ると登録する（ボタンは出さない）
