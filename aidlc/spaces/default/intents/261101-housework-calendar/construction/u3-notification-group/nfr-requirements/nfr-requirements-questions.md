# NFR 要件 — U3 お知らせ先 — 質問

U3（`u3-notification-group`）の速さ・安全・信頼性などの決まりを決めます。U1・U2 で決めたことは、そのまま U3 にも使います。もう一度は聞きません。

- LINE のトークの返事は 95% が 10 秒以内、画面は 95% が 3 秒以内
- Webhook の署名の確かめ、同じイベントを二度処理しない、思いがけない失敗は 500
- 返事は reply だけ（push は使わない。費用 0 円）
- ログは 1 行 1 件の JSON で 30 日、秘密の情報は書かない
- テストは Vitest と Gherkin、行カバレッジ 80% 以上

機能設計で決めたこと（グループの名前の受け取りは 2 秒で打ち切る、など）も聞きません。U3 で新しく出てきた、グループの情報の扱いだけを聞きます。

## Q1. [セキュリティ] グループ ID をログに書くか

LINE のグループ ID は秘密の情報ではありませんが、どの家族のグループかを示す値です。登録・断った・外された、のできごとのログに、グループ ID をどう書くかです。

A. グループ ID の先頭 6 文字だけを書く（U2 の招待の印と同じく、見分けるのに使う）。全体は書かない
B. グループ ID の全体を書く（ログから LINE の管理画面の情報と突き合わせやすい）
X. Other (please specify)

[Answer]: B

## Q2. [セキュリティ] グループの名前の持ち方

家族の設定の画面に出すグループの名前は、家族が付けた名前で、個人の名前などが入っていることがあります。

A. 登録のときに 1 回だけ LINE から受け取り、DynamoDB に残す（画面を開くたびに LINE を呼ばない）。お知らせ先を外したら、名前も一緒に消す。ログにはグループの名前を書かない
B. DynamoDB には残さず、家族の設定の画面を開くたびに LINE から受け取る（LINE の API の呼び出しは無料。画面が少し遅くなる）
X. Other (please specify)

[Answer]: A
