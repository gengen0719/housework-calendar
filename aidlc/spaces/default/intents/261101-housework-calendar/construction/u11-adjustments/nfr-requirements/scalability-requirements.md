# U11 規模・費用要件

## Requirements

| ID | 目標 | 確認方法 |
|---|---|---|
| NFR1.201 | ステージングと本番合計で月100円以内を目標とする既存予算を継承し、追加ストレージ・読取・書込・バックアップを既存費用へ加算して配備前に再評価する。追加LINE通知は0通 | インフラ差分と想定利用量で見積もる。無料枠残量・為替・実測未確認なら条件付きと明示。予算通知は強制停止ではない |
| NFR3.201 | 常時稼働サーバー・新しいLambda・新しい定時ジョブを増やさず、既存画面APIと通知のC9経路へ組み込む | 構成差分の確認 |
| NFR7.203 | 1家族4人、月1000件の調整を性能検証前提とし、件数制限を業務仕様へ追加しない。読取は全ページを扱い、部分結果を合計として返さない | 複数ページ・1000件・同じ入力の並行10要求の試験。負荷超過は明示的な失敗とし無限再試行しない |

## Capacity Planning

1件の理由は最大100コードポイント。登録時に行と操作結果、削除時に行の除去、表示時に対象月の全行を読む想定で見積もります。家族・月で絞れない全体走査を新しい通常経路に設けません。年度をまたぐ保存件数とバックアップ増分も配備前の見積に含めます。
