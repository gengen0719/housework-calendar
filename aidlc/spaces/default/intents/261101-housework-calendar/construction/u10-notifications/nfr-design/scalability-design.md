# 容量・費用設計 — U10 お知らせ

NFR3.101〜NFR3.103、NFR1.101〜NFR1.102を対象とする。家族の列挙は100件以下のページで進め、続きの印がある限り処理する。家族ごとの仕事を永続キューへ渡し、最大2並行で処理する。キューの重複は通知の一意記録で抑止する。失敗した家族だけが再試行され、他の家族の処理を止めない。

本文は1通へまとめる。外部配信先の上限を超える場合、複数通へ勝手に分割せず失敗として知らせる。名前に含まれる改行・制御文字は通知用の区切りを偽装しない形へ整え、黙って担当や子供の行を落とさない。家族4人・担当100件という試験基準が外部上限へ収まらない場合も、その失敗が安全に扱えることを確認する。表示名の長さによる最悪値をインフラ・コード計画で検証する。

容量の警戒値はキュー待ち30秒超、最古の対象通知120秒超、残り期限60秒未満。並行数を増やす場合は、配信先の制限・他の入口の性能・費用を確認して設定変更する。無制限の自動拡張を採用しない。

月の自発通知は家族あたり最大32通。再試行を別通として受理させない。処理の起動・キュー・保存・監視・メールの費用も見積もりに含める。具体的なAWSのサービス選択と東京リージョンの単価・無料枠はインフラ設計で確認し、0円を未確認のまま保証しない。
