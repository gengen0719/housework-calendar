# 機能設計 — U4 お手伝いの種類 — 質問

U4（`u4-chore-types`）では、管理者（お母さん）がお手伝いの種類（名前・単価・説明）を登録・変更し、「使わない」にしたり、割り当てに使われていない種類を消したりできるようにします。受け持つ受け入れ条件は AC2.1.1〜AC2.1.7 です（AC2.1.4 の金額の計算は U9、AC2.1.5 の割り当てで選べないことは U5 で確かめます。U4 は「記録のときに書き写す今の単価」を答える窓口と、「使わない」の印を作ります）。

すでに決まっていること（もう一度は聞きません）:

- 登録・変更・使わない・消すは管理者だけ。子供は断る（AC2.1.3）
- 単価は 0 円以上の整数。-1、小数、空欄は「単価は 0 円以上の整数で入力してください」と出し、入力した内容は残す（AC2.1.2）
- 単価を変えると、そのあとに付いた記録から新しい単価を使う。すでに付いた記録の金額は変わらない（FR2.2。記録のときに単価を書き写す。ADR-003）
- 「使わない」の種類は新しい割り当てでは選べず、過去の記録とお小遣いは残る（FR2.3）
- 割り当てに一度も使われていない種類だけ消せる。使われたことがあれば消せず、「使わない」にするよう案内する（FR2.4、AC2.1.6）。「使われたか」はカレンダーが持つデータなので、U5 ができるまでは「使われていない」として扱う
- 新しく作る操作は、送り直しを 1 回として扱う（`Idempotency-Key`。U1 の BR2.8）

ここでは、入力の細かい決まりと、画面の置き場所を聞きます。

## Q1. [プロダクト] お手伝いの名前の決まり

A. 前後の空白を除いて 1〜20 文字で必須。同じ家族の中で同じ名前は登録できない（「使わない」の種類も含めて）

X. Other (please specify)

[Answer]: A、ただし例えば「皿洗い」は一日一回とは限らないのでそういう場合は「皿洗い（追加分）」のように登録することを促したい

## Q2. [プロダクト] 単価の上限

[Answer]: C
