# 人物像（Personas）

`user-stories-questions.md` の Q1 で決めたとおり、人物は 2 つです。もとにしたのは `inception/requirements-analysis/requirements.md` と、前の段階の書類（`ideation/intent-capture/intent-statement.md`、`stakeholder-map.md`）です。

## P1. 母親（管理者）

| 項目 | 内容 |
|------|------|
| 名前の例 | お母さん |
| 役割 | 家族を作った管理者。家族で話し合って決めた割り当てを入力し、記録を確認・修正し、月を確定する（requirements の FR1.3、FR3、FR6） |
| 目的 | お手伝いの回数を数えてお小遣いを計算する手間をなくす。子供の記録を確認するだけで済ませる（intent-statement） |
| 困っていること | 紙やホワイトボードでの管理に限界がある。回数の数え間違いがある。記録が残らない（intent-statement） |
| 使う場所 | スマホの LINE の中と、パソコンのブラウザ（requirements の FR1.6） |
| 使う頻度 | 月初に割り当てを入力するとき、記録を確認するとき（数日に 1 回程度）、月末 |
| ITへの慣れ | ふつう（LINE とアプリの画面が使える） |

## P2. 子供（家族のメンバー）

| 項目 | 内容 |
|------|------|
| 名前の例 | 太郎・花子・次郎（3 人。例として使う名前） |
| 役割 | 招待されて家族に参加したメンバー。自分の担当を見て、やったら記録する。都合が悪い日は、ほかの子供に代わってもらう（requirements の FR1.4、FR5、FR7） |
| 目的 | 自分の担当がすぐわかる。やった分のお小遣いが正しく数えられる |
| 困っていること | いつ何をやるかを忘れる。取り掛かるのが遅くなる（intent-statement） |
| 使う場所 | 自分のスマホの LINE（小学校高学年〜中高生、全員が自分のスマホと LINE を持っている）（intent-statement） |
| 使う頻度 | ほぼ毎日（16 時のリマインドを見たとき、お手伝いが終わったとき） |
| ITへの慣れ | 高い（LINE を日常的に使っている） |

## 人物どうしの関係と優先度

- 1 つの家族に、母親（P1）が 1 人、子供（P2）が 3 人いる（requirements の NFR1）
- 子供どうしは、担当を「代わりにやる」で引き受け合う（requirements の FR7）
- 優先度: どちらも欠かせない。母親が割り当てを入力しないと子供は記録できず、子供が記録しないと母親の手間は減らない（intent-statement の成功の目安）
