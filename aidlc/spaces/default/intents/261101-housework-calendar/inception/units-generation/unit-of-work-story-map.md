## 単位をまたぐストーリー

### US1.1 家族を作って子供を招待する（U1 と U2）

最初の形（U1）をできるだけ小さくするため、招待の部分を U2 に分けました [Q3]。

| 受け入れ条件 | 単位 | 中身 |
|-------------|------|------|
| AC1.1.1、AC1.1.2 | U1 | 友だち登録の記録（重複しない） |
| AC1.1.3〜AC1.1.5 | U1 | 家族を作る・招待を待つの表示、家族を作る、2 つ目は作らない |
| AC1.1.10 | U1 | ブラウザで LINE にログインして開く |
| AC1.1.11 | U1 | 家族のメンバーではない人に中身を見せない |
| AC1.1.12 | U1（仕組み）、各単位（それぞれの管理者の操作） | 認証のない要求、ほかの家族からの要求、子供による管理者の操作を断る |
| AC1.1.6〜AC1.1.9 | U2 | 招待用のリンクを作る、参加する、別の家族の人と無効なリンクを断る |
| AC1.1.13 | U2 | 子供は招待用のリンクを作れない |

AC1.1.12 の管理者の操作は、それぞれ次の単位で断ることを確かめます: 招待用のリンク（U2）、お知らせ先の登録（U3）、お手伝いの種類（U4）、割り当て（U5）、取り消し・済にする・やらなかったにする・外す・確定と取り消し（U7）、加算・減額（U11）。

### ほかの単位にまたがる受け入れ条件

1 つの単位に割り当てたストーリーでも、一部の受け入れ条件はほかの単位の働きと合わせて確かめます。テストでは、受け入れ条件の前提データ（`stories.md`）のとおり、ほかの単位が作る状態を前提データで用意できます。

| ストーリー | 受け入れ条件の内容 | 関わる単位 |
|-----------|------------------|-----------|
| US1.2 | お知らせ先がないとき 16 時と月末 21 時に何も送らない（AC1.2.4） | U3（画面の表示）、U10（送らないこと） |
| US1.2 | 登録されていないグループでの申し出を断る（AC1.2.5） | U3（決まり）、U8（申し出） |
| US5.1 | 記録がすぐお小遣いの額に反映される（FR5.8） | U6（書き写し）、U9（額の表示） |
| US8.1 | 加算・減額を内訳に含める（FR8.1） | U9（計算）、U11（加算・減額） |
| US9.1 | 月末のまとめの額に加算・減額を含める | U10（まとめ）、U11（加算・減額） |

## 単位ごとの作る中身の順

それぞれの単位の中では、チームの決まり（BDD）のとおり、先に受け入れ条件から Given/When/Then の筋書きを書き、それが通るまで作ります（`team.md` の Testing Posture）。単位の中の順は次のとおりです。

| 単位 | 単位の中の順 |
|------|------------|
| U1 | AWS CDK の土台とステージングへの配備 → 友だち登録の記録と返事 → LINE ログインで画面を開く → 家族を作る → 認証と家族のメンバーの確かめ |
| U2 | 招待用のリンクを作る → リンクで参加する → 断る場合 |
| U3 | グループへの参加の受け取り → お知らせ先の登録と置き換え → 子供を断る → 登録がないときの表示 |
| U4 | 種類の登録・変更 → 今の単価の窓口 → 使わない → 消す |
| U5 | 割り当ての保存と日ごとの担当（US3.1） → 担当の変更と作り直し → カレンダーと日ごとの表示（US4.1） |
| U6 | リッチメニューからの記録と返事 → 選べない担当と二重の記録 → 画面からの記録 → 断る場合 |
| U7 | 状態の表（FR6.1）の変わり方 → 取り消し・済にする・やらなかった → 月の確定と取り消し → 子供を断る |
| U8 | 申し出とボタン → 引き受ける → 取り下げる → 自動でなくなる決まり |
| U9 | 種類ごとの単価 × 回数の合計 → 内訳の表示 → マイナスと 0 円の表示 |
| U10 | 16 時のリマインド → 月末 21 時のまとめ → 二重に送らない → 失敗の知らせ |
| U11 | 加算・減額の記録 → 消す → 確定している月を断る → 額とまとめへの反映 |
