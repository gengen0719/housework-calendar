# 部品と色の対応（Design System Mapping）

画面の部品と色の約束ごとです。もとにしたのは `refined-mockups-questions.md` の回答（Q1〜Q5）、`ideation/rough-mockups/wireframes.md`、`inception/requirements-analysis/requirements.md` の NFR9（見やすさ）です。

## 部品集

- スマホ向けの既製の部品集を使う（Q1）。どの部品集にするかは、設計の段階（functional-design）で決める
- 部品集が決まるまでは、下の「部品の対応」の名前（ボタン、知らせ、など）で呼ぶ
- 部品集の部品をそのまま使い、見た目は下の「色」と「文字と余白」だけを上書きする

## 色（デザインの約束ごと）

主な色は LINE に近い緑（Q2）。文字と背景の色の差は 4.5:1 以上にする（NFR9）。LINE の緑（#06C755）は白い文字との色の差が足りないため、ボタンなどの塗りには濃い緑を使う。

| 名前 | 色 | 使うところ | 色の差の目安 |
|------|-----|-----------|--------------|
| 主な色 | #00873C（濃い緑） | 主なボタンの塗り、選んでいるタブ | 白い文字に対して約 4.6:1 |
| 主な色（薄い） | #E6F7EC | 自分の担当の枠の背景（Q5）、選んでいる日の背景 | 本文の文字に対して 4.5:1 以上 |
| 自分の担当の枠 | #00873C（主な色と同じ）、太さ 2px | 自分の担当を目立たせる枠（Q5） | 白い背景に対して約 4.6:1（部品の目安 3:1 以上） |
| LINE の緑 | #06C755 | 飾り（線やアイコンの一部）だけ。文字や塗りには使わない | — |
| 本文の文字 | #1F2937 | 本文、見出し | 白い背景に対して約 15:1 |
| 補助の文字 | #4B5563 | 時刻、説明 | 白い背景に対して約 7.5:1 |
| 背景 | #FFFFFF | 画面の背景 | — |
| 状態: 済 | #1B5E20（文字）＋「済」の文字 | 担当の状態 | 白い背景に対して 4.5:1 以上 |
| 状態: 未 | #4B5563（文字）＋「未」の文字 | 担当の状態 | 白い背景に対して約 7.5:1 |
| 状態: × | #B91C1C（文字）＋「×」の文字 | 担当の状態（やらなかった） | 白い背景に対して約 6.5:1 |
| 注意 | #B91C1C | 入力の誤り、取り消しなど元に戻しにくい操作のボタン | 白い背景に対して約 6.5:1 |

状態は必ず文字（「済」「未」「×」）と一緒に表し、色だけで伝えない（NFR9）。正確な色の差は、作る段階で確かめる道具で測る。

## 文字と余白

| 名前 | 値 | 使うところ |
|------|-----|-----------|
| 本文 | 16px | すべての本文 |
| 小さい文字 | 14px | 時刻、補足。これより小さくしない |
| 見出し 1 | 20px 太字 | 画面の見出し |
| 見出し 2 | 18px 太字 | 日付やお手伝いごとの見出し |
| 余白の単位 | 8px | 余白は 8px の倍数にする |
| 押す場所 | 44×44px 以上 | ボタン、チェックボックス、タブ、日付のマス（NFR9） |
| 押す場所どうしの間 | 8px 以上 | 隣り合うボタン |

## 部品の対応

| 画面の部品 | 部品集の部品 | 使う画面 |
|-----------|--------------|----------|
| 下のタブ | タブバー（下部ナビゲーション） | すべての画面（`mockups.md` の全体の構成） |
| 月の切り替え | 前へ・次へのボタン付きの見出し | S1、S4 |
| カレンダー（スマホ） | 週ごとの縦の一覧 | S1 |
| カレンダー（パソコン） | 7 列の表 | S1（Q3） |
| 担当の行 | 一覧の行（状態の文字、名前、時刻） | S1、S2 |
| 主なボタン | 塗りのボタン（主な色） | 保存、確定、家族を作る |
| ほかのボタン | 枠線のボタン | やめる、戻る |
| 注意のボタン | 枠線のボタン（注意の色） | 記録を取り消す、やらなかったにする |
| 入力欄 | 見える名前付きの入力欄 | S3、S6 |
| 子供の選択 | 選択の一覧（ドロップダウン） | S4、S6 |
| 曜日の選択 | 名前付きのチェックボックス | S4 |
| 加算・減額の選択 | 名前付きのラジオボタン | S6 |
| 確認 | 確認の小窓（ダイアログ） | 取り消し、やらなかった、確定、確定の取り消し、割り当ての上書き、加算・減額を消す |
| 短い知らせ | 画面の下に出る短い知らせ（トースト）。ボタンは付けない | 記録・修正のあと（Q4） |
| 読み込み中 | 枠だけの仮の表示（スケルトン） | S1、S2、S5 |
| 空の表示 | 説明と次の操作のボタン | S1、S3、S5 |
| 失敗の表示 | 説明と「読み込み直す」ボタン | S1、S2、S5 |
