# お知らせ運用手順

U11では外向き通知とバックアップを分離しました。`STAGING_BACKUPS_ENABLED` / `PRODUCTION_BACKUPS_ENABLED`を明示trueにすると、通知falseのまま既存03:00のバックアップだけ有効にできます。メール購読・実機試験・合算100円以下の予算確認はバックアップにも必要です。実行障害/DLQの警報アクションは有効、通知の欠測警報・SQS・日次/月末送信は無効のままです。省略時は従来の通知フラグを継承し、新規の既定は両方無効です。対象に調整表を追加し、表/prefixを分けて7日保存します。詳細と復元・読取互換な戻し方は[加算・減額の運用](adjustment-runbook.md)を参照してください。

## 有効化

初回はすべて無効で配備します。通知用の公開URLはありません。SSMの環境別 `line/channel-access-token` と `notifications/operational-hash-key` を設定し、環境別SNSのメール購読確認を終えます。運用鍵はランダムに作ってSSMへ保存し、コンテキストやログに渡しません。値の記載例は `<作り物の値>` のみです。

GitHub変数の `STAGING_` / `PRODUCTION_` に続けて `NOTIFICATIONS_ENABLED`、`NOTIFICATION_EMAIL`、`NOTIFICATION_CHECKS_PASSED`、`NOTIFICATION_BUDGET_VERIFIED` を設定します。合算額は共通 `NOTIFICATION_TOTAL_ESTIMATED_JPY` です。有効化するにはメール、購読・実機試験の確認、費用確認、0〜100円の合算額がそろう必要があります。これらは秘密ではなく、実際の値をコードへ入れません。API/LINEの既存OIDCとproductionの手動承認を通して反映します。

検査は既存CIの全体VitestにU10も含まれます。`npx vitest run u10-notifications` が単位の確認です。現環境のgitleaks未導入は未実施として扱い、ツールを導入した端末で既存 `npm run secrets:scan` を配備前に実行します。

## 停止と調査

異常時は該当環境の有効フラグをfalseにして通常のCDK反映でSchedulerとSQS連携を止めます。実行中の15分窓が過ぎるまで待ち、記録やキューを消して再送を誘発しません。送信済み・期限切れをpreparedへ書き換えたり、別キーで再投入したりしません。

調査は予定日・種類・familyRefで定型ログから始め、Dispatchesのstate/version/attempts/leaseを読みます。本文やLINEの応答そのものをログへ貼りません。送信済みは再送しません。送信結果が不明なら同じキーでしか照合せず、15分の期限を超えたら作り直しません。送信先が変わった仕事は新しいグループへ複製しません。

RUNは列挙完了とexpected/completedを持ち、0家族も完了になります。家族の完了マーカーで重複を数えません。5分以上未完了、SQS最古年齢120秒以上、watchdog失敗はNotifyHealthと定型メールで追います。watchdogが止まると欠測アラームになります。DLQは自動再投入しません。不正入力と期限切れを区別して原因を直し、古い仕事を別キーで送り直さないでください。

## 清掃と復旧

Payloadsは終端時削除、23時間以上を毎時清掃、24時間以後は読取窓口が拒否します。清掃カーソルは失敗した日を保持します。Dispatchesの35日TTLは日別の削除ポインタも使って補います。

バックアップはDispatchesだけ。作成ARNをBACKUPSパーティションの台帳へ保存し、台帳を失っても必ず自テーブル名付きListBackupsで照合します。表ARN・バックアップ名・ARNのprefixを確かめ、7日を過ぎた自分のバックアップだけDescribe後に削除します。作成応答不明や台帳保存失敗はメールで調査します。

復旧中は起動/SQS連携を無効にし、DynamoDBの正式な復元手順で別の表へ戻します。現在の15分窓を過ぎたことを確認し、CDKの参照を通常の変更手順で切り替えます。本文表は復元せず、失った本文を再計算して過去の通知を再送しません。次の通常予定から始めます。本番の記録の直接書換えはしません。

## 費用

上限目標はstagingとproductionを合算して月100円。設計の仮定は各環境1家族4人、SQS135万要求、DynamoDB30万RRU/2万WRU、バックアップ0.07GB月、無料枠に余裕がある既存アカウントです。設計時の計画換算200円/USDと税等10%の余裕では約56円ですが、実際の料金・為替・税ではありません。GetMetricStatistics/PutMetricData約18万API/月も他のAPI利用を含め無料枠の残りを確認します。

予算は0.50USDで80%実績と100%予測の通知を使います。請求は強制停止されません。無料枠、実要求数、換算と税を検証して100円を超える構成は有効化しません。LINEは環境別の無料アカウントで家族あたり最大32通、4人の例で128通以内を確認します。未測定の空ポーリングや無料枠を0円と断言しません。
